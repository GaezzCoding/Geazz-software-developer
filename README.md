## 🛠 What I'm building

**5Wezir** is a marketplace for Turkmenistan: every seller has their own store and product cards.
It starts with my own store — with a cash register, a seller panel and a buyer app.

| Part | Stack | Status |
| --- | --- | --- |
| Cash register (web) | Next.js · Mantine | ✅ Done |
| Backend | Kotlin · Spring Boot · PostgreSQL · Flyway | 🚧 In progress |
| Seller panel | Next.js · TypeScript | 🚧 In progress |
| Marketplace admin | Next.js · TypeScript | ⏳ Next |
| Buyer app | Android · Jetpack Compose | ⏳ Planned |
